## Segment audit: 2026-10-25

Reproducible analysis: `audit/analyze.py`; results: `audit/coverage.json`.
Host-only trace preserves actual segment boundaries. Graph21 target verification has20segments,62 contiguous gate/up/GLU triples and53 same-segment quadruples:39Q3,8Q5,6Q4. SevenQ6 triples useF32 down. TwoQ5 triples end beforequantization at segment boundaries. These are syntactic opportunities, not proven DAG eligibility.

Every full quadruple aliases packed matvecB input with quantizer output. Never write fused quantization there while other CTAs still readB. Preferred implementation uses persistent separate packed-output storage and rewrites the proven single down consumer's Bdescriptor. Prove consumers over the full graph, including views/exports, before recording; refuse ambiguous cases. Native prealloc quant-cache resets pergraph, but later same-graph consumers still require proof. Preserve raw gate/up/F32GLU outputs. Descriptor registration and buffer lifetime must follow existing pending-slot infrastructure. No speculative memory-order weakening.

All53 quadruples have marker counts(0,1,1): no gate/up marker, one beforeGLU, one beforequant. Removing these two requires complete fused dependency proof. The marker beforedown remains. Flattening segments hides command-buffer synchronization; a missing flat marker across segments is not a baseline bug.

Existing old rowwise gate/up+GLU and Q3 B-reuse variants already had negative quiet C1 performance. Reusing their exact helpers is useful, but merely porting that design is not a new optimization. New hypothesis is32row CTA, native Q8packing and separate scratch, retaining unifiedFA. No new shader implemented or speed claim yet.

Native op25 quantizer has64lanes,8lanes per32value block. Each lane loads4 contiguous values. Preserve max(max(abs.x,abs.y),max(abs.z,abs.w)), clusteredMax8, d=amax/127, reciprocal conditional, round(vals*d_inv), pack32(i8vec4(round(vals))), left-associated x+y+z+w, clusteredAdd8 and f16vec2(d,sum*d). Existing GLUquant helper uses the same sequence. A32row CTA can use8lanes percolumn with this exact grouping; all lanes participating in each subgroup collective must execute it uniformly, including inactive groups with zero values and suppressed stores. WG staging must provide the original contiguous row order. Separate ds entries are32bit f16vec2 stores, while each qs store is32bit: validate SPIR-V store width to exclude adjacent-field write races.
