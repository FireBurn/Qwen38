# Historical decode budget

Run analyze.py to regenerate budget.json from the pinned historical byte audit and quiet native/mega comparison. The trace accounts for 15.692 GB of logical matrix weights per token. Q4/Q5 contribute 56.16%; Q6 contributes 15.90%. At the R9700's specified peak 640 GB/s, a hypothetical single read of each byte takes 24.52 ms. This is an idealized weight-stream estimate, not a hard latency bound: cache reuse, extra transactions, activations/KV, compute, scheduling and overlap are not modeled. AMD source: https://www.amd.com/content/dam/amd/en/documents/partner-hub/radeon-pro/radeon-ai-pro-r9700-datasheet.pdf .

The historical quiet full-stack comparison was 34.203 ms/token for mega and 31.495 ms/token for native: a 2.708 ms gap. They use different core/ggml ABIs, so that gap cannot be attributed only to the shader. Equivalent logical weight rates are 458.8 and 498.2 GB/s, not measured DRAM counters. This comparison is historical; a fresh matched comparison is still required for a final win claim.

These scales guide prioritization. A focused GLU saving estimated around 0.086 ms per token would only close about 3% of that historical gap if it transferred unchanged. Many small independent gains could accumulate, but code size, register allocation and scheduling interact. The next portfolio needs quiet individual-versus-combined measurements. The largest opportunity remains making dominant matrix streaming and recurrent/attention execution more efficient, or safely reusing a weight read across useful token work; merely increasing theoretical dot throughput cannot bypass unchanged weight traffic.

`local_gain_scenarios.py` adds an explicitly hypothetical Amdahl sensitivity check from pinned budget and Q3 diagnostic sources. The measured6.134%Q3 dispatch-time reduction would yield~1.18%total throughput uplift *if* Q3 took19.036%of total time (the historical logical-byte share, not a measured time fraction). The historical baseline gap requires7.917%total latency reduction/8.597%throughput uplift. Therefore the focused Q3 lead motivates combination testing and further dominant-matrix work; it does not by itself imply closing the native gap. These are sensitivity examples, not transferred model results.
