# Native GPU argmax: measured follow-up required

Pinned aa8 argmax.comp launches one workgroup per row. Host pipeline specializes BLOCK_SIZE to device subgroup_size (ggml-vulkan.cpp pipeline_argmax_f32). Each lane scans K/B inputs serially, then shared-memory tree reduction. A full-vocabulary target greedy row therefore exposes only one subgroup of parallelism. This is a source-level bottleneck hypothesis; no measured critical-path attribution or speed gain yet.

Possible small kernel change: bounded chunked first-stage argmax followed by final pair reduction, optionally gather chosen ID/logit in the final stage. Exact arithmetic requires comparisons only, not reassociation of head dot products. Added dispatch/scratch/ownership costs may dominate smaller rows; keep native path below a measured crossover. First qualify existing backend temperature-only sampling and observe actual tensor dimensions/timing. No owncompile/GPU work during current fixed48.

For finite logits, native shader chooses earliest within each lane for ties, then the reduction tree favors bit-reversed lane order among equal maxima. Tie rank is (bit_reverse(original_index modulo native BLOCK_SIZE), original_index), not global smallest index or lowest lane. For BLOCK_SIZE4 and logits[0,1,1,0], native chooses index2 rather than1. The earlier lowest-lane inference was incorrect; the source-model CPU check in check_argmax_tie_order.py validates this corrected finite comparator against exhaustive small arrays. A hierarchical implementation must preserve this order for equivalence to native GPU argmax; CPU legacy top-k tie behavior is separately unstable and cannot be equated. NaNs, infinities, all-negative-infinity and native initializer behavior require dedicated tests/fallback, not assumed mathematical max semantics. Dimensions below BLOCK_SIZE and multiple rows also need checks.

Do not fuse output-head partial maxima before preserving dot-product accumulation/quantization behavior and measuring native argmax critical cost. Two-stage argmax/gather is a smaller independent experiment before head fusion.
