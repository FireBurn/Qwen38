# Current DFlash operator profile

Run one isolated installed-server process with the observed DFlash width4 and sampler, the same local cached model and draft, q8 KV, FA and 327680 context allocation. Use the same one-dword copy and disabled-transfer-queue child overrides as the bounded smoke test. Enable the installed Vulkan per-operation performance logger with a high report frequency; it may insert barriers and synchronization and is unsuitable for throughput or critical-path claims. Generate a 16-token warmup and one fixed short 32-token synthetic request on a loopback-only server. Capture full logs, output hash, draft counts, library/model identities, CPU telemetry and device errors. Stop on new GPU errors, competing inference, timeout or server failure; no retry. A valid profile requires DFlash activation, the copy override, a nonempty response and emitted Vulkan timing tables. The trace includes prefill, warmup and draft/target work and cannot be converted directly into model-speed or per-stage attribution. It does not qualify a candidate shader or model output beyond the sampled run. Preserve the broader private GPU hold and the quarantined failed boundary test.
