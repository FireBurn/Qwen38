# Attention divergence control without Flash Attention

Use the same fixed synthetic two-sequence empty-KV input, split-width dynamic and Q/K/V projections, mapped private baseline/candidate libraries and intrusive captures as ATTENTION-PLAN.md, but explicitly disable Flash Attention in both contexts. Compare Q/K/V and pre-output-projection attention tensors. This separately tests whether the observed difference persists in the non-FA path; it does not establish a model speed change or recommend disabling Flash Attention. The non-FA graph and its intermediates can introduce their own numerical differences. Require in-process library/driver mapping, graph shape, no competing inference, one-dword copy, disabled transfer queue and fault monitoring; stop on errors, timeout or invalid captures. Preserve the general GPU hold.
