# Dynamic-convolution intermediate diagnostic

Instrument the split baseline and two-sequence iswa candidate with identical graph labels on the first layer's dynamic projection and on the dynamic convolution's tap inputs, weights and products. Use the same fixed synthetic empty-KV two-sequence probe and actual target/draft weights as the earlier mapped diagnostic. Capture the relevant tensor values with an intrusive evaluation callback, verify in-process library and RADV mappings and trace the graph shape. Compare corresponding sequence rows using recorded dimensions and strides. This experiment diagnoses the first observed difference; callback synchronization changes execution and cannot support a speed result. Stop on missing mapping, incomplete capture, competing inference, new GPU error or timeout. The usual private one-dword-copy/no-transfer-queue safeguards and GPU hold apply.
