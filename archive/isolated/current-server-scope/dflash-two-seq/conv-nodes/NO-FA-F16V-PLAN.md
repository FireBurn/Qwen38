This separately defined diagnostic changes V cache to F16 in both baseline and candidate while leaving K at Q8 and Flash Attention disabled. It can show whether a difference exists under this alternate path and cache type, but cannot isolate FA alone relative to the original Q8/Q8 run or qualify the production configuration.
