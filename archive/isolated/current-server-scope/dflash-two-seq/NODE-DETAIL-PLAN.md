# First-layer divergence diagnostic

The prior separately instrumented one-input comparison verified each library mapping and showed identical input embeddings but substantially different first-layer outputs between split and merged DFlash2 graphs. This new diagnostic captures intermediate first-layer tensors, including normalization, dynamic convolution, Q/K/V, attention-side outputs and feed-forward tensors, to locate the earliest observed difference. It uses the same actual weights and fixed synthetic empty-KV input with private baseline and candidate libraries, process-local safety overrides, pinned in-process mappings and fault/competition monitoring. The callback is intrusive; captures do not qualify speed. Handle tensor shapes and strides correctly, and compare only corresponding logical elements. Stop on faults, incomplete captures, missing mappings or invalid tensors, without retry. Existing broader hold stays active.
