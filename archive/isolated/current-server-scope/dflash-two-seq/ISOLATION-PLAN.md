# Fixed two-sequence draft isolation probe

Use the same target and draft GGUF files as the observed server, but a private standalone C++ probe with a short 2048-token allocated context, q8 KV, flash attention and two sequences. The target context is used for the shared draft weights; the draft KV starts empty. Run four fixed ten-token draft batches per process: base anchors, change only sequence 0's anchor, change only sequence 1's anchor, repeat base. Clear draft memory between batches. Capture the complete 10-row selector lattice per case and flushed case/graph trace markers. This tests synthetic token blocks using actual weights, not prefilled current-server states, target outputs, cache rollback, long contexts or sampling quality.

Run a private baseline first, verify that repeating the base is exact and that changing one sequence leaves the other sequence's five lattice rows bit-identical. Then run the two-sequence candidate with the same inputs and verify isolation, repeatability, and full baseline/candidate byte equality. Require candidate graph trace blocks=2/tokens=10 after a case marker and baseline single-sequence graphs; graph construction during the decode call plus successful output is evidence of the exercised shape, not proof of every device operation. Use process-local one-dword copy, disabled transfer queue, pinned library mappings and model stat identities. Monitor new GPU faults and competing inference while the child runs; stop immediately on a fault, timeout, wrong map, missing markers, invalid capture, or baseline failure. Do not retry or change the system installation. This is correctness, not performance, and the general GPU hold otherwise remains.
