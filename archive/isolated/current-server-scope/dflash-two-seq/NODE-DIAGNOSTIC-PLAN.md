# Fixed input intermediate-node diagnostic

The previous iswa-candidate isolation study produced a merged graph, but its candidate process exited before the external mapping sampler obtained its maps. Captured outputs differed from the split baseline. This separately scoped diagnostic adds in-process mapping verification and an evaluation callback that captures selected graph tensors for one fixed empty-KV two-sequence input: token embeddings, initial layer outputs, final normalized hidden state, logits and selector lattice where available. The callback synchronizes and changes execution, so no timing data are meaningful. Run rebuilt split baseline then the already-built iswa candidate with identical weights and inputs, compare compatible tensor shapes and the first observed divergence. Require the in-process expected private libllama mapping and RADV mapping, graph traces, valid node data, no competing inference and no new GPU errors; abort on error or timeout without retry. The candidate is still unqualified. Maintain the existing fault hold for other work.
