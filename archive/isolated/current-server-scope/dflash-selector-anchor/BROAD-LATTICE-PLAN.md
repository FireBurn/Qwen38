# DFlash selector broader single-sequence check

Compare baseline and candidate serially on two additional seeded synthetic workloads: maximum draft width 3 with a populated prompt made from repeated technical text and a math question, and width 4 with a coding question. Generate 128 requested tokens per case after a fixed warmup. Keep the same private libraries, lattice hook, one-dword-copy/disabled-transfer-queue controls, output checks, mapping checks and GPU fault hold exceptions as the initial lattice check. Save all lattice bytes locally and compare exact hashes/bytes, seeded response hashes, and draft/accept counts; record actual prompt token counts. Stop on any process error, missing capture, mismatch or new GPU fault, without retry. This is still single sequence and two prompts with one seed; it does not qualify long context, multi-sequence behavior or speed.
