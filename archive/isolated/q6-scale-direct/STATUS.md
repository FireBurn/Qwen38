# Q6_K scales loaded directly from immutable metadata

Alternative to the original LDS handoff and subgroup-shuffle candidate. Only op01 changes. Four signed scales per lane come from the existing packed16 weight metadata via signed bitfield extraction. Scale conversion and all float dequantization, FMA and reduction orders remain unchanged. No new weight storage or activation quantization is introduced.

The build checks both byte positions in every signed 16-bit word (131,072 cases), and the source byte index for every lane/scale. It compiles and validates a distinct SPIR-V artifact. GPU checks must start at 16 groups; resources must be measured before larger tests. The standalone operator witness covers six widths, partial superblocks and odd rows. Model stress and timing remain unqualified until corresponding results exist.

Expected tradeoff: remove shared-memory stores, reads, synchronization and cross-lane shuffle, while adding per-lane immutable metadata loads. Same metadata bytes remain in the weight block. Effective memory traffic, load combining and cache reuse are not established by source analysis. No speed or quality claim yet.
