# Q3 shared activation bias

Derived from the integer correction idea in upstream PR30517, with a different sharing boundary. Existing op27 subtracts four from every weight byte using a packed xor/subtract/xor sequence, for each row. This candidate leaves decoded weights unsigned 0..7 and precomputes -4*sum(16 signed Q8 activation values) once per j/col cohort. Both existing output rows reuse it. The correction becomes the initial integer accumulator; final integer result and all float scale/reduction math stay unchanged. Other operators and FA are unchanged.

Cost tradeoff: four extra activation-sum dot4 instructions per two-row cohort plus bias calculation, against removal of packed byte recentering for both rows. Memory traffic and activation quantization are unchanged. Register pressure and compiler scheduling can erase this benefit. No performance claim until measured.
