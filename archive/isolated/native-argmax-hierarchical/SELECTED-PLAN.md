# Selected boundary and special-value comparisons

Run seven fixed cases serially, each stock followed by hardened hierarchical host, as separate fresh processes using the pinned private driver, one-dword copy and no transfer queue. Cases `(K, rows, pattern)` are `(2047,1,0)`, `(2048,1,6)`, `(2049,2,2)`, `(4095,5,9)`, `(4096,1,13)`, `(4097,5,0)`, `(248320,5,3)`; these cover fallback, exact/cross-chunk boundaries, ties, NaNs, infinity plus NaN, and multirow execution. Exact result bytes must match stock per case, paths and hashes must match, candidate dispatch must be positively marked at K>=2048 and absent below threshold, and no new GPU errors may appear. Stop on the first discrepancy, timeout or fault without retry; retain the broader hold. This is a focused correctness check, not a stress test, full numerical/model qualification or performance evidence.
