# Fixed operator timing: hardened hierarchical vs wide

Compare the existing qualified wide shader with the hardened hierarchical path using the same hardened private backend, one-dword copy, no transfer queue, K=248320, 16 argmax-plus-gather copies, 60 synchronous iterations and 16 warm graphs. Run 24 fresh processes in six alternating ABBA/BAAB blocks. Baseline sets the wide shader; candidate sets the hierarchical directory. No audit logging in timed runs; separate bounded checks establish path activation, and pinned assets are rechecked. Verify exact selected values and indices and no new target GPU errors. Stop on first failure, no retry, extension or pooling. Record whole-process CPU busy, build count, runnable threads and optional natural GPU clock/power. A block matches when CPU busy differs by at most 5 percentage points, build count by at most 2, and runnable count by at most the greater of 4 or 15% of the arm mean. Analyze per-block log candidate/baseline time ratios and descriptive t intervals. A negative upper bound in at least four matched blocks justifies broader model correctness and an independent model A/B, not a model speed claim. The global fault hold and failed boundary-test quarantine remain in force except for this exact reviewed diagnostic.
