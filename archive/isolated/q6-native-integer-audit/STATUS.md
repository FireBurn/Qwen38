# Native Q6 integer-path prefilter

Source audit: the frozen host already compiles Q6_K/Q8_1 matvec but automatically disables its selection on AMD, citing two-byte alignment of 210-byte Q6 blocks and a historical Intel-only win. GGML_VK_FORCE_MMVQ overrides that policy. No host or system changes are needed to compare it on a standalone graph containing only Q6 matrices. This override is child-process-only and is never applied to the user's model.

Four small native probes completed: K5120/17408,R3, float/forced-integer, two matrices each. Actual tape dispatch keys prove float versus Q8-activation integer selection. The unknown Q6 integer shader was first exercised with at most three workgroups; quantization uses the previously known Q8 kernel. Backend maps verified, all outputs finite. Integer changes arithmetic: normalized output RMS errors1.8315%/1.2347%, max absolute0.07522/0.08057 for the two synthetic shapes. This is not model-quality evidence or approval. No bit-exact claim and no timing interpretation under compilation.

An eight-matrix native operator harness is compiled and pinned for a quiet prefilter. run_q6_integer_after_rows.py waits on existing Q3 row followerPID3483447 with identity/start-tick checks and a completed three-mean/six-row predecessor summary. Then run_q6_integer_quiet_bench.py waits for30s compiler-free/lowCPU/noinference, compares float/integer/integer/float for both K5120/R17408 and K17408/R5120,512repeats/16warmups. Actual frozen driver maps, backend path, pins, finite outputs, per-mode determinism and first-three-row agreement with the small native probes are required. Compiler/competing inference aborts, CPU/clocks recorded. Wall operator timing includes quantization/dispatch; it is not a mega/fullmodel result. No performance result exists yet.

The ordinary performance logger inserts synchronization and a graph-end fence; its concurrent mode still measures groups between hazard boundaries. It is unsuitable as an interchangeable substitute for the existing mega dispatch-only timestamps. This native comparison therefore waits for quiet wall-time measurement. A speed improvement, if found, would only justify a separate selective Q6 port and subsequent model quality evaluation. Blanket forcing on the full model would also change other operator choices and has not been done.
