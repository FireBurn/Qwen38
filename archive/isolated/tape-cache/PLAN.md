# Exact resident serialized-tape reuse

Read-only audit host (../tape-reuse) proves repeated actual post-fusion serialized ranges: short settled graph19/19segments and699392bytes match, long prompt changes offsets/segmentation and has both hits and misses. Audit did not skip any upload. Both9-frame outputs exact.

Cache mode is opt-in GGML_VK_MEGA_TAPE_REUSE, bindless verify0 inside a graph transaction. Shader unchanged current bounds; all current one-row-gather/norm/BF16fusions retained. Every physical256byte record in both16MiB parity halves has a validity byte. Retained mapped HOST_COHERENT stage is the exact CPU shadow; skip upload only if EVERY record is valid and full serialized bytes match with memcmp. GPU tape is declared readonly and has no GPU writers. Source scan finds only this host staging memcpy and GPU copyBuffer writer. Segment IDs/lengths can change: physical-range validity plus updated staging handles overlaps without stale-key assumptions.

On hit skip only staging memcpy and copyBuffer. Counter offsets/clears, barriers, descriptors, PC, resident grid, dispatch and submit order remain original. On miss update CPU stage, record the original GPU copy, THEN mark range valid. All preceding successful graph uploads are submitted in queue order by build_graph/compute_forward; completion need not be assumed because existing device memory barriers are kept. Current-graph ranges are monotonically increasing, so their prior-parity cache trust cannot be invalidated by another offset. Normal graph completion commits transaction only after recording/submission and optional synchronize; exceptions/uncommitted/nested transactions invalidate metadata. Explicit init/backend cleanup/free and changed context/buffer/stage/capacity invalidate. Flush outside active graph never uses cache and invalidates on upload. No cancellation may leave trusted unsubmitted uploads. No graph/counter cache or GPU-data cache.

CPU witness covers exact/miss, uninitialized records, changed record, size growth, overlapping writes, untouched prefix, parity, GPU/context/capacity changes, malformed ranges, commit, cancellation, exceptions and explicit invalidation. Loader ABI2 plus unique state type, same shader96VGPR/16KB and64first checks. Both9/65prompts, matching fusion counts/hits/misses, paired4K n96/r3 then fuller n256/r4. Natural128 and actual4K FA coverage before promotion; trace throughput excluded. No shared/Claude/installed modifications.
