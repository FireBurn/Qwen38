# Lossless Q3 repacking into four-bit slots

Hypothesis: Q3 is still below the card's logical streaming rate because of unpacking/masking/scales. Expand each110-byte Q3 block into a144-byte Q4-shaped container, preserving all256values, original12scale bytes and half scale bits exactly. Payload nibbles store unsigned0..7; the shared-activation correction preserves original signed values-4..3. The extra30.91% storage buys simpler native four-bit extraction and removes hmask loads/bit assembly. More traffic may outweigh the reduced decode work. This is not quantization, pruning or an approximation.

CPU proof covers raw byte layout and integer partial dots. Operator-only shader uses Q4 containers for repacked Q3 with original Q3 scale interpretation; normal Q4 weights would be misinterpreted. NEVER use this shader for a full model. A future model port would require separate shadow-weight buffers/descriptors and preserving original storage for native prefill/fallback, plus memory/lifetime and model correctness proofs. No such host port exists. Original GGUF and queued shader artifacts unchanged.
