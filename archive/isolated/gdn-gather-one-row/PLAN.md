# Remove a provably redundant one-row initial-state gather

Primary transfer lead: rdna-oct22-refresh/gdn-state-gather-skip.patch (pinned upstream). Its delayed row-ID lifetime bug motivates a narrower exact shape proof rather than unprotected pointer substitution. Current target has exactly ONE cache row, one scalar I32 row index, and one gathered state. Under GET_ROWS valid-index precondition the only legal index is zero. No index read needs moving or snapshotting at all. Multi-row caches remain generic. Single-token/sequence/K1 only.

Shader is byte-for-byte current bounds reference: NO new shader logic, arithmetic, flags, index reads, reductions or allocations. Host rewrites only the GDN input descriptor from gathered state to its original one-row cache and deletes the GET_ROWS record. Keep packed output state/copy unchanged; no in-place destination alias experiment. Existing fusers run first; gather pass runs last. Generic/native slot-learning fallback is retained because only a completed same-flush record pair can fuse.

Graph proof resolves logical GET_ROWS view roots/ranges. Gather transient COMPUTE allocation, F32 contiguous, exact3MiB; input cache F32 contiguous shape[786432,1,1,1], exact3MiB; single I32 index. Every nonempty computational reader must be exactly one GDN source5 covering full gather at offset0 with H48/T1/seq1/K1. Reject exported/input gather/view or leaf aliases, extra readers, malformed/out-of-range view chains. Metadata-only views read nothing; zero-sized consumers are ignored.

Runtime fuser additionally requires exact29-word captured GET_ROWS PC, producer tag, known original kernel keys, source/output descriptor sizes/disjointness, GDN shape/flags/input slot match. Reject ANY intervening access overlapping cache or gathered output, including extra descriptor slots added by other fusions (conservative cover of every write). Reject source cache overlapping any other GDN input or packed output. Thus cache cannot change between original gather point and GDN, no lost gathered-state observers, no changed input/packed-output alias. Preserve all barriers and compact duplicate ones only. Disable verify modes and experimental GDN-QK fusion.

CPU witness covers positive shape plus rejection of multiple cache rows, extra readers, exports, missing/duplicate GDN use, tokens/sequences/snapshots, shifted state, cyclic views and noncompute allocations. Unique private C++ state type prevents benchmark dynamic-loader destructor collision. Loader-help/ABI preflight, then both9frames64groups, both65frames192, paired micro; full timing/logits/coverage before promotion. No current-reference/Claude/production edit.
